# Android 界面设计与验收边界

设计契约：`ark × maximal`，在 `ArkUi.family/depth` 中声明。使用系统字体、原创几何背景和原生 View，不包含游戏标志、人物图、专有字体或官方前端资源。

参考依据为 ark-ui-skill 的 Ark 分支：黑色边缘导航、青色活动状态、蓝图舞台、下方大标题与有索引的档案列表。来源模式见 [明日方舟公开站点](https://ak.hypergryph.com/)及[新闻列表](https://ak.hypergryph.com/news)。这是独立实现的视觉语言参考，不是官方 UI 或源码。

## 页面覆盖

- 地图：黑白青主框架、状态栏、原创网格与角标、未配置时的大标题、API 入口、定位与投稿动作。配置后原生地图成为主舞台，网格不伪装为真实底图。
- 档案：索引编号、分类筛选、匹配数量、选中地点与实际坐标。详情组织为地点信息、前往方式及媒体内容，标记不依赖地图 Key 所属账号。
- 投稿：门店档案、地理位置、图像与授权三个区段；选点时让出地图，回到表单保留编辑内容。等待与失败使用真实业务状态。
- 个人 API：解释费用与存储边界、离线教程、当前包名/签名复制、独立平台输入、启用及清除。
- 投稿进度、登录和反馈：沿用同一文字、表面、表单与动作色。长文及系统对话框刻意降为 complex 的阅读密度，避免无用装饰。

竖屏使用底部模式切换，短屏一次聚焦地图或档案；宽屏/横屏采用地图与档案两栏，按可用空间重新分配。状态、选中区域与页面切换触发短横向显现，按钮使用原生触摸反馈；系统关闭动画时保留相同静态内容，不运行装饰循环。
